# Thai copy style — BlessMe supplier voice

English note: this guide is for Thai page copy only. Do not reuse wording from other companies. Patterns below were observed, then rewritten in BlessMe’s own words.

ใช้กับข้อความภาษาไทยบนเว็บขายส่ง เป้าหมายคือให้อ่านเหมือนพนักงานขายส่งคุยกับเจ้าของร้าน ไม่ใช่บทโฆษณาที่เขียนทีละย่อหน้ายาว

ดูวิธีเรียงข้อมูลจากหน้าสินค้าของบริษัทวัตถุดิบเครื่องดื่มในไทยสองแห่ง (เมษายน–ตุลาคม 2026) แล้วเขียนใหม่ทั้งประโยค ไม่ยกประโยคหรือรูปของเขาไปใช้

หน้าที่ดู:

- หน้าแรก หน้าท็อปปิ้ง หน้าขายส่ง และหน้าเกี่ยวกับเรา ของบริษัทวัตถุดิบชา
- หน้าไข่มุกป๊อปสองขนาด และหน้าบุก ของบริษัทจัดจำหน่ายท็อปปิ้ง

## โทนที่เอาแบบ

- คุยกับร้าน ใช้คำว่า ร้าน สั่ง ของ แพ็ค ไม่ต้องยัดคำว่า คุณ ทุกประโยค
- ประโยคสั้น จบทีละเรื่อง ราคาเท่านี้ แพ็คเท่านี้ เก็บยังไง สั่งที่ไหน
- ขึ้นต้นด้วยชื่อสินค้า แล้วบอกว่าเม็ดเป็นยังไง ใส่แก้วอะไรได้
- สเปกแยกเป็นตารางหรือบรรทัดที่มีป้าย เช่น ขนาดแพ็ค น้ำหนักเนื้อ อายุก่อนเปิด วิธีเก็บหลังเปิด ราคา ไม่ฝังตัวเลขไว้กลางย่อหน้าโฆษณา
- รายการรสเขียนเป็นชื่อกับขนาดแพ็คพอ ไม่วางคำขยายสามคำติดกัน
- ปุ่มสั่งชัด ทัก LINE @blessmethailand หรือสั่งปลีกที่ Shopee เบอร์โทรและอีเมลเขียนตรง ๆ
- หัวข้อเป็นชื่อเรื่องธรรมดา เช่น สินค้า ราคาส่ง เก็บยังไง ไม่ใช้สโลแกน

## สิ่งที่เว็บคู่แข่งไม่ได้ทำ และเราไม่ทำ

- ไม่เขียนแถลงการณ์แบรนด์บนหน้าสินค้า
- ไม่สัญญาผลยอดขาย รางวัล หรือจำนวนร้าน ถ้าไม่มีตัวเลขในข้อมูลสินค้า
- ไม่ใส่เลขทะเบียนอาหาร ใบรับรอง หรือราคาที่ไม่มีอยู่ในข้อมูลเดิม
- คำฮือฮาที่บางหน้าของคู่แข่งยังใช้ เราไม่เอาตาม เช่น การยกสินค้าให้ดูหรู หรือการบอกว่าบริการครบทุกอย่าง

## คำและรูปประโยคที่ไม่ใช้

- ไม่ว่าจะเป็น แล้วตามด้วยรายการยาว
- ยกระดับ ครบจบในที่เดียว จุดแตกต่างที่แท้จริง ประสบการณ์ใหม่ พาร์ทเนอร์ (ใช้ ร้าน)
- ประโยคยาวที่คั่นด้วยขีดยาว
- คำขยายเรียงสามคำ เช่น ประณีต หรูหรา ล้ำสมัย
- ซิกเนเจอร์ พรีเมียม โซลูชัน ถ้าพูดตรง ๆ ได้ว่า ขายส่ง สินค้า วิธีสั่ง
- คำว่า คุณ ซ้ำทุกบรรทัด
- จุดจบประโยค ภาษาไทยใช้เว้นวรรคหรือขึ้นบรรทัดใหม่ จุดที่เหลือได้มีแค่ทศนิยม อีเมล และ URL เช่น 4.50 กับ Blessme.team@gmail.com

## ข้อเท็จจริงที่ล็อกไว้

- ขายมุกป๊อปธัญพืช (ข้าวบาร์เลย์ ข้าวโอ๊ต ถั่วแดง) โมจิโยเกิร์ต และบุกหอมหมื่นลี้ตามที่หน้าสินค้ามี นำเข้าจากโรงงานผู้ผลิตในจีน
- บุกหอมหมื่นลี้เป็นท็อปปิ้งบุก ไม่ใช่มุกป๊อป ไม่มีมุกแห้ว
- สะกด ป๊อป
- หัวข้อที่มี มุกป๊อป หรือ ไข่มุกป๊อป อยู่แล้ว ให้คงคำนั้น
- บทความคงย่อหน้าตอบตรงใต้หัวข้อใหญ่
- ราคา ขนาดแพ็ค น้ำหนักเนื้อ อายุเก็บ คำเตือนเด็ก กลูเตน น้ำเชื่อม และช่องทางสั่ง ใช้ตัวเลขและประโยคที่มีอยู่ในข้อมูลเดิม
- ไม่แตะข้อความอังกฤษ URL schema hreflang canonical redirect และการวัดผล

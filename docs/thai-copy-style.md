# Thai copy style — BlessMe voice

English note: this guide is for Thai page copy only. Read it before writing or editing any Thai text on the site, by hand or with AI. The goal is copy that reads like a person who runs a drink shop talking to another shop owner. If a sentence would sound strange said out loud across a counter, rewrite it.

## เราเป็นใคร (ใช้เล่าได้)

เบลสมีมีร้านเครื่องดื่มของตัวเอง (Blessme สมูทตี้บาร์ และส้มใส่ใจ น้ำผลไม้คั้นสด) เราเลยรู้ว่าหน้าร้านต้องการท็อปปิ้งแบบไหน นี่คือจุดที่ต่างจากซัพพลายเออร์ทั่วไป ใช้เล่าได้เต็มที่ (เรื่องเล่าที่ละเอียดกว่านี้ เช่น ใช้ในร้านตัวเองก่อนไหม ให้เจ้าของยืนยันก่อนใส่)

## เขียนยังไงให้เป็นเสียงคน

- พูดในนามร้าน ใช้ "เรา" ได้ เล่าว่าเราใช้ยังไง ลูกค้าเราชอบแบบไหน
- กล้ามีความเห็น เช่น "ใส่ลาเต้เย็นคือเข้ากันสุด" "ร้านที่เพิ่งเริ่ม ลองตัวนี้ก่อน" ความเห็นเรื่องรสชาติและวิธีใช้พูดได้ ไม่ต้องมีตัวเลขรองรับ
- ใช้คำที่คนไทยพูดจริง เช่น กรุบ หนึบ แตกในปาก หอม ๆ นวล ๆ คุ้นปาก โปะ ตัก สบาย ๆ
- ประโยคยาวสั้นไม่เท่ากันบ้าง อ่านแล้วมีจังหวะ ไม่ต้องสมบูรณ์แบบ
- คำลงท้ายใช้ได้ประปราย เช่น นะ เลย ได้เลย ไม่ต้องใส่ทุกประโยค
- หัวข้อสั้นแบบที่คนพูด เช่น "ราคาส่ง" "เก็บยังไง" "สั่งยังไง"

## สิ่งที่ทำให้อ่านแล้วเป็น AI (ห้าม)

- **ประโยคออกตัว** เช่น "เป็นข้อเสนอให้ทดลอง ไม่ใช่ผลยอดขาย" "ไม่ใช่ผลสำรวจราคาคู่แข่ง" "ไม่ใช่ผลลัพธ์จริงของลูกค้า" "ยังไม่รวมค่าใช้จ่ายอื่น" ซ้ำทุกย่อหน้า ถ้าไม่ได้อ้างตัวเลขเท็จอยู่แล้วก็ไม่ต้องออกตัว ถ้าจำเป็นจริง (เช่นเครื่องคิดกำไร) ใส่หมายเหตุบรรทัดเดียวที่เดียว
- **พูดซ้ำ** เรื่องเดียวกันเกินหนึ่งครั้งในหน้าเดียว โดยเฉพาะ "บุกหอมหมื่นลี้ไม่ใช่มุกป๊อป" บอกครั้งเดียวในจุดที่เหมาะ (การ์ดบุก) พอ
- **บอกสิ่งที่ไม่ใช่แทนสิ่งที่ใช่** บอกว่าบุกเคี้ยวหนึบ ดีกว่าบอกว่าไม่ใช่มุกป๊อป
- **แปลตรงตัวจากอังกฤษ** เช่น "เน้นพืชเป็นหลัก" "แบบวัตถุดิบเอเชีย" "รสสะอาด" "ของเหลวแกน" "เม็ดบีด" "ร้านที่กำลังดูสินค้า" "ยินดีรับการสอบถาม" "ไม่ได้ลงของทุกอย่าง"
- **ยัดคีย์เวิร์ด** เช่น "บางคนเรียกเม็ดป๊อป หรือเขียนว่ามุกป๊อบ" "ไข่มุกป๊อปคือชื่อที่ร้านใช้เรียกมุกป๊อป" คีย์เวิร์ดไปอยู่ใน title, meta, alt รูป ส่วนเนื้อหาใช้คำว่า มุกป๊อป คำเดียว
- **ลิสต์สามอย่างทุกประโยค** และคำขยายเรียงสามคำ
- **ขีดยาว (—)** คั่นกลางประโยค
- คำโฆษณาเกิน: ยกระดับ ครบจบ ประสบการณ์ใหม่ พรีเมียม โซลูชัน ซิกเนเจอร์

## คำที่ใช้ให้ตรงกันทั้งเว็บ

| เรื่อง | ใช้ |
| --- | --- |
| ชื่อสินค้า | มุกป๊อป |
| แบรนด์ (หน้าไทย) | เบลสมี |
| หน่วยบรรจุ | แพ็ค |
| ราคาในประโยค | 90 บาท / บนป้ายราคา ฿90 |
| น้ำหนัก | 500 กรัม, 300 กรัม, 15 กรัม |
| หน่วยเสิร์ฟ | แก้ว |
| ประมาณ | ประมาณ / ราว (ไม่ใช้ ~) |
| ขายส่ง | ขายส่ง (ไม่ใช้ ค้าส่ง) |
| ไม้ยมก | เว้นวรรคหน้าหลัง: ใหม่ ๆ |

จุดจบประโยคไม่ใช้ ภาษาไทยใช้เว้นวรรคหรือขึ้นบรรทัดใหม่

## ข้อเท็จจริงที่ห้ามเปลี่ยน (เรื่อง อย. และความปลอดภัย)

- ราคา ขนาดแพ็ค น้ำหนักเนื้อ อายุก่อนเปิด วิธีเก็บหลังเปิด ใช้ตัวเลขเดิม
- คำเตือนที่ต้องมี: บรรจุในน้ำเชื่อมมีน้ำตาล, ไม่แนะนำเด็กต่ำกว่า 6 ปี (เสี่ยงสำลัก), บาร์เลย์และโอ๊ตมีกลูเตน เขียนให้เป็นภาษาคนได้ แต่ความหมายต้องครบ
- ห้ามเคลมสุขภาพ (ดีต่อสุขภาพ อิ่มนาน วิตามิน ฯลฯ) ห้ามเคลมฮาลาล ใบรับรอง หรือเลข อย. ที่ยังไม่ได้ยืนยัน
- ห้ามเคลม "ขายดีที่สุด" หรือตัวเลขยอดขายที่ไม่มีหลักฐาน ตัวเลขที่ใช้ได้ตอนนี้คือ Shopee 4.9 ดาว และขายไปแล้วกว่า 10,000 แพ็ค (รสโอ๊ตและบาร์เลย์)
- บุกหอมหมื่นลี้เป็นเม็ดบุก ไม่ใช่มุกป๊อป (บอกครั้งเดียวต่อหน้า)
- ไม่แตะข้อความอังกฤษ URL schema hreflang canonical redirect และการวัดผล
